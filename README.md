# 🚀 Space Wars: A Python Turtle Arcade Game

Welcome to **Space Wars**, a classic-style arcade game created using Python's `turtle` module. In this game, you pilot a spaceship and must dodge and destroy enemies, avoid allies, and maximize your score using keyboard controls. Built and tested in Replit, but should work locally as well with a standard Python 3 installation.

---

## ✅ **Step 1: Prerequisites**

Ensure you have **Python 3** installed. This game uses the standard `turtle` module which is included in most Python installations.

---

## ✅ **Step 2: Remix and Run the Game on Replit**

To quickly play or test the game without installing anything locally:

1. Visit the Replit project page: [Space Wars on Replit](https://replit.com/@hussainaltufayl/SpaceWar?v=1#main.py)
2. Click the **"Remix this App"** button at the top right.
3. This will create a personal fork you can run and edit.
4. Click the green **"Run"** button to launch the game.

A new game window will open inside Replit with the play area.

---

## ✅ **Game Controls**

Use the following keys to control the spaceship:

* **Left Arrow** ← : Turn left
* **Right Arrow** → : Turn right
* **Up Arrow** ↑ : Accelerate
* **Down Arrow** ↓ : Decelerate
* **Spacebar** : Fire missile

---

## 🔧 **How to Play**

* Your ship starts at the center of the screen.
* **Left** and **Right Arrow Keys**: Rotate your ship left or right to change direction.
* **Hold Up Arrow**: Accelerate the ship forward.
* **Hold Down Arrow**: Decelerate the ship.
* **Press Spacebar**: Shoot lasers in the direction your ship is facing.

### Objective

* Destroy red enemy ships to earn points.
* Avoid blue ally ships or you will lose points.
* Colliding with enemies or allies can lower your score.
* Keep your ship within the game boundaries.
* Your score is displayed in the top-left corner.

---

## ✅ **Gameplay Overview**

* **Player** (white triangle): Your spaceship
* **Enemies** (red circles): Avoid or destroy them with missiles (+100 points)
* **Allies** (blue squares): Avoid hitting them or you'll lose points (-50 to -100 points)
* **Missiles** (yellow triangle): Fires in the direction your ship is facing
* Score is displayed at the top-left corner

### Features

* Enemy and ally collision detection
* Scoring system
* Border wrapping
* Real-time keyboard controls

---

## ✅ **Important Notes**

* Works best on a standard desktop environment with GUI support.
* Turtle graphics may behave differently or not display on some remote IDEs or headless systems (e.g., some Linux VMs).
* The game window is fixed at **400x400** pixels.
